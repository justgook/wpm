🧩 WASM Plugin SDK - Browser Demo

ℹ️ Info: This demo shows how to use the JavaScript SDK to load and run WebAssembly plugins in the browser. The same WASM files work with both the Go SDK (server-side) and this JavaScript SDK (browser).
⚠️ Note: Make sure to serve this page from a web server (not file://) and that your WASM plugin files are accessible. You can use: python3 -m http.server 8000 from the project root directory.
